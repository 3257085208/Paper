## 对论文的含义

1. **三资源超售实锚**：vCPU 8.3×、内存 2.0×（配额普遍 512 MB 起）、磁盘 4.9×（薄分配）——测试床的 5×
   量级不是人为拔高；且"内存超售靠小配额 + 低实际占用"与"磁盘靠薄分配 + 模板共享"是行业常规手法。
2. **运行数动态**：配置 285 / 运行 276 / 某 3 小时窗口 210——生命周期事件频繁，印证冷启动与短历史问题。
3. **稀有重载结构**（见 `PRODUCTION_ANALYSIS.md`）：71.9% 近闲 + 1.0% 重载，配合 8.3× 超售长期共存——
   与"高密度必须依赖相位/占用结构"的结论一致。
